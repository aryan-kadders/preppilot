## Summary
Better interview answers: PrepPilot understands each question first, then answers with a short description and clear points. Updates now download only what changed.

## What's new
- PrepPilot works out the question the interviewer meant before answering, even when a word is misheard (for example "asylum" for Agile).
- Answers start with a short description, followed by clear bullet points.
- Answers are fuller: complete explanations instead of one-liners.
- Any question that needs code (including SQL queries) shows the code in the code panel.
- Answers start faster, and no longer get stuck waiting.
- Better recognition of interview words such as Agile, Scrum, BRD, SRS and SOW.
- Mock interview feedback and meeting notes now work when you are signed in with an invite code.
- Your sessions and mock interviews are shared with your team's admins and kept for 90 days.
- New in Settings › Audio: "Practice alone" answers questions you ask into your own microphone.
- Every computer needs your team's invite code before it can be used.
- Undetectable is on every time PrepPilot starts.
- From this version on, updates download only the parts that changed.
